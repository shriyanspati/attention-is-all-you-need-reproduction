# Reproducing "Attention Is All You Need"

### A From-Scratch Transformer Implementation and Reproducibility Study

**Author:** Shriyans Pati

A comprehensive implementation and validation of the Transformer architecture introduced in *Attention Is All You Need* (Vaswani et al., NeurIPS 2017). This project reproduces the original model entirely from scratch while emphasizing mathematical correctness, rigorous testing, and reproducible machine learning research.
